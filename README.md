## Development (Wails 3)

The Go framework, CLI and `@wailsio/runtime` are pinned to **v3.0.0-beta.28**.
Requires Go 1.25+ and Node.js 20.19+ or 22.12+.

```sh
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.28
wails3 task dev
wails3 build
```

On Linux, install GTK 4 and WebKitGTK 6.0 development libraries (`libgtk-4-dev`
and `libwebkitgtk-6.0-dev` on Ubuntu). Windows requires WebView2 and a C compiler
for the HID backend; macOS requires Xcode command line tools. CGO must remain
enabled for real HID acquisition. When cross-compiling Windows from Linux, use
an appropriate MinGW compiler, for example:

```sh
CC=x86_64-w64-mingw32-gcc wails3 build GOOS=windows ARCH=amd64
```

Builds go to `bin/`. `bash scripts/build-all.sh` still collects versioned Linux
and Windows binaries in `dist/`; `--nsis` also creates Windows installers
(requires `makensis`). On macOS, `wails3 package` creates an app bundle.

Bindings are generated by the build task into `frontend/bindings/`. After changing
exported Go methods, regenerate them with `wails3 generate bindings -ts -i`.
The Vite plugin handles the Wails runtime and bindings during frontend development.

```sh
go test ./...
cd frontend && npm run check && npm run build
```

Without native GUI libraries, the backend tests can run with
`CGO_ENABLED=0 go test -tags server ./...`; this does not exercise HID hardware
or native desktop windows. Wails 3 is currently a beta release.
